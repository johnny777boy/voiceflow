# VoiceFlow

Native macOS menu bar app for system-wide push-to-talk dictation with AI-assisted
cleanup and reliable, destination-protected text insertion.

Personal, macOS-only. Not a SaaS product.

Development happens on the `feature/system-dictation-daily-use` branch inside a
git worktree under `.worktrees/`. See `IMPLEMENTATION_PLAN.md` in that worktree.
